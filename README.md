# سیرکل (Circle)

شبکه‌ی اجتماعی **اعتمادمحور** برای خرید، فروش و معرفی خدمات بین خانواده، دوستان، آشنایان و همکاران — به‌جای ارتباط با غریبه‌ها.

> در دیوار و شیپور آدم‌ها غریبه‌اند. در سیرکل، هر آگهی از یک **مسیر اعتماد** به شما می‌رسد.

این نسخه یک **نمونه‌ی کاربردی فرانت‌اند** (موبایل‌فرست، فارسی RTL) با داده‌های نمونه است. همه‌ی جریان‌ها قابل کلیک‌اند؛ داده‌ها در `localStorage` مرورگر ذخیره می‌شوند (بک‌اند واقعی هنوز اضافه نشده).

## اجرا

```bash
npm install
npm run dev
# http://localhost:3000
```

برای بازنشانی داده‌ها، `localStorage` مرورگر را پاک کنید (کلید `circle-store-v1`).

## امکانات این نسخه

- **فید آگهی‌ها** با فیلتر نوع (فروش، خدمات، اهدا، معاوضه، قرض) و جستجوی فارسی (نرمال‌سازی ی/ک)
- **حلقه‌ی من**: افزودن افراد، تعیین نوع رابطه و سطح اعتماد (A/B/C)
- **مسیر اعتماد**: نمایش زنجیره‌ی «فروشنده ← کاوه ← مینا ← شما»
- **بج و توصیه**: تأیید کالا / شناخت فروشنده / تأیید کیفیت / سابقه‌ی معامله
- **حریم خصوصی واقعی**: آگهی‌های خارج از محدوده‌ی اعتماد در فید پنهان و در جزئیات قفل می‌شوند
- **درخواست‌ها**: ثبت نیاز و دریافت **پیشنهاد** از حلقه
- **نشان‌شده‌ها**: ذخیره‌ی ماندگار آگهی‌ها
- **پیام‌ها**: گفتگوی تک‌به‌تک با حباب چت، شمارش نخوانده
- **پروفایل عمومی هر فرد**: اعتبار، آگهی‌ها، درخواست‌ها و مسیر اعتماد
- **حالت تاریک** (روشن / تیره / سیستم) با ذخیره‌ی ماندگار و بدون پرشِ رنگ
- **آنبوردینگ** اولین ورود، **toast** بازخورد، **اسکلتون لودینگ** و انیمیشن ورود کارت‌ها
- نصب‌پذیر (PWA) با مانیفست و آیکون

## ساختار

```
app/
  page.tsx                فید خانه + میان‌برها + آنبوردینگ
  circle/page.tsx         حلقه‌ی من + افزودن فرد
  new/page.tsx            ثبت آگهی
  listing/[id]/page.tsx   جزئیات آگهی + مسیر اعتماد + بج‌ها
  requests/page.tsx       درخواست‌ها + ثبت درخواست
  request/[id]/page.tsx   جزئیات درخواست + جریان پیشنهاد
  saved/page.tsx          نشان‌شده‌ها
  messages/page.tsx       لیست گفتگوها
  messages/[id]/page.tsx  صفحه‌ی چت
  person/[id]/page.tsx    پروفایل عمومی فرد
  profile/page.tsx        پروفایل اعتماد من
components/               ListingCard, RequestCard, TrustPath, Toast, Skeleton, ...
lib/
  types.ts                مدل داده
  mock-data.ts            افراد، آگهی‌ها، درخواست‌ها، پیشنهادها، پیام‌های نمونه
  labels.ts               برچسب‌های فارسی + فرمت قیمت
  persian.ts              ابزار اعداد/نرمال‌سازی فارسی
  trust.ts                محاسبه‌ی امتیاز اعتماد و اعمال حریم خصوصی
  store.tsx               استور سمت کلاینت (Context + localStorage)
```
